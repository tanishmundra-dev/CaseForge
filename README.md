# CaseForge by Scaler

AI-native learning and assessment platform for enterprise workforce transformation.

## What it does

- Converts plain-English scenarios from BU leaders into graded case studies using LLMs
- Provisions sandboxed lab environments per case (APIs, repos, tools — all synthetic and safe)
- Auto-assesses trainee submissions against rubrics; flags borderline cases for human review
- AI companion provides real-time contextual guidance via voice/text
- Analytics for managers and trainees

## Training Streams

- Forward Deployed Engineer
- AI Context Manager
- Model Validator
- Agentic Ops Engineer
- Orchestrator
